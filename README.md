# Sri Padma Electronics — portfolio website

A responsive, animated electronics-store portfolio based on the supplied Google Maps listing.

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome or Edge.

## Add actual products and photos
1. Click **Manage products** at the bottom-right.
2. Enter the exact product name, category, price (optional), description, availability and badge.
3. Upload the product image and click **Add product**. Use **Edit** or **Delete** to maintain the catalogue.

The starter catalogue is a category scaffold based on public shop context (DTH, remotes, audio and accessories), not a verified complete stock list. Replace these entries with the exact products in the shop.

## Important limitations
- Changes and uploaded images are stored only in the current browser's local storage. They are not synced to other devices, and clearing browser data can remove them.
- This is a front-end portfolio, not a secure inventory system. Before public launch, connect a database and image storage and add an administrator login.
- The Google Maps listing link identifies the shop but does not provide a downloadable, structured product catalogue to this project. Upload the original shop/product photos you own or are allowed to use through **Manage products**.
